Geräteübergreifend speichern

Damit du dich anmelden und von mehreren Geräten auf dieselben Daten zugreifen kannst, brauchst du ein kostenloses Supabase-Projekt (übernimmt Anmeldung + Speicherung). Einmalig einrichten:

  1. Kostenlosen Account auf supabase.com anlegen, neues Projekt erstellen.
  2. Im Projekt links auf "SQL Editor" → "New query", den Code unten einfügen und ausführen.
  3. Unter "Project Settings" → "API": Project URL und anon public Key kopieren.
  4. Beides unten eintragen und speichern.
create table if not exists public.stundenzettel_data ( user_id uuid primary key references auth.users(id) on delete cascade, data jsonb not null default '{}'::jsonb, updated_at timestamptz not null default now() ); alter table public.stundenzettel_data enable row level security; create policy "select_own" on public.stundenzettel_data for select using (auth.uid() = user_id); create policy "insert_own" on public.stundenzettel_data for insert with check (auth.uid() = user_id); create policy "update_own" on public.stundenzettel_data for update using (auth.uid() = user_id);
